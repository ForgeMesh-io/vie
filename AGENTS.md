# Instructions for AI agents — VIE

VIE is a community fork of XCL. Preserve the Windows x86-64 baseline while working toward native Linux and macOS runtimes. Read [LEGAL.md](LEGAL.md), [CONTRIBUTING.md](CONTRIBUTING.md) and the [ForgeMesh rules](https://github.com/ForgeMesh-io/nexus/blob/main/AGENTS.md). Use English for project artifacts.

- Check the [coordination issue](https://github.com/ForgeMesh-io/vie/issues/1), existing VIE PRs, and relevant upstream work before starting. Use `.forgemesh/tasks/` and add evidence to an existing thread when it covers the outcome.
- Use the [roadmap](ROADMAP.md) to scope work. Name the OS, CPU architecture, exact commit, commands and skips in any test report. Do not treat a build, a Windows binary under Wine, or a translated x86-64 game as proof of direct native game execution.
- Read-only tasks do not require a machine probe or a game. After trust verification, ask privately about a game copy only if relevant; never ask for its path, contents, keys or uploads. Use synthetic fixtures and independently verify what they actually cover. Native execution requires explicit, task-specific consent; do not run candidate code outside an approved sandbox by default.
- Do not copy from incompatible sources, execute upstream code merely because it is public, or expose proprietary data or private logs. Keep patches focused; do not reformat the upstream tree.
