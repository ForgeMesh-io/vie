# Security

VIE runs game code with the rights of your account. It is not a sandbox. Do not run untrusted game executables or unverified builds.

Report security issues privately through [VIE's GitHub security advisories](https://github.com/ForgeMesh-io/vie/security/advisories/new). Include the exact commit, the impact, and a minimal description. Do not attach game files, dumps, keys, or private logs. Issues that affect upstream XCL should also follow [XCL's reporting instructions](https://github.com/xcl-dev/xcl/security/policy).
