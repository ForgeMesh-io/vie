# Legal rules for VIE

These rules are protected (CODEOWNERS). Breaking them gets a contribution rejected and may get an account blocked.

1. **Never commit** game executables, packages, dumps, decrypted or extracted game code or assets, console firmware, keys, certificates, or any Microsoft GDK/XDK file, header or documentation that is not public.
2. **No leaked material.** Do not use, cite or link leaked SDKs, source code or documents, even "for reference".
3. **Licences.** Import code only under licences compatible with Apache-2.0 (MIT, BSD, Apache-2.0, Zlib, ...), with the source URL, commit and licence recorded in `THIRD_PARTY.md`. GPL/AGPL projects (see `research/MATRIX.md` §3) are behaviour references only: describe facts in prose, never copy code. Projects without a licence are all-rights-reserved: do not copy.
4. **Clean-room separation.** Someone who studied GPL code in detail writes a prose specification; the implementation is written from that spec.
5. **Your own copies only.** Tasks that need a game (e.g. VIE-0009) run locally on the participant's own legally obtained copy. Only derived facts (instruction lists, measurements) are published.
6. **No claims without evidence.** Compatibility or performance statements need a log, a measurement with hardware described, or a reproducible test.
7. **Trademarks.** Product names are used only to describe compatibility goals.
