# Legal rules for VIE

- **Licence.** VIE inherits XCL's [GPL-2.0-only licence](LICENSE). Check that linked or adapted code is compatible with it. Apache-2.0-only, GPL-3.0-only, and unlicensed code are not automatically reusable. Keep notices, date changes to imported files, and document the source, commit and licence in [THIRD_PARTY.md](THIRD_PARTY.md).
- **Upstream sync.** The initial XCL commit predates [XCL #905](https://github.com/xcl-dev/xcl/pull/905). XCL documents a project-specific permission for its VIctory-derived code. Before merging any upstream history that includes it, verify downstream redistribution rights or use a reviewed compatible import that excludes it. Deleting the code after merging does not remove it from history.
- **No proprietary or leaked material.** Do not commit or share games, packages, dumps, keys, firmware, proprietary console SDK material, raw game traces, or decrypted or extracted assets. Do not add DRM circumvention. Use self-built, redistributable fixtures. Optional private tests use only your own lawfully obtained copies, with separate consent; share only redacted outcomes.
- **Support claims and attribution.** Report the exact revision, OS, CPU architecture and observed result. Product names describe compatibility goals and do not imply affiliation or endorsement.
