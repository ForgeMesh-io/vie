# VIE — ForgeMesh swarm

**Status: research.** No code yet, nothing runs, no compatibility claims.

VIE aims at an independent, Vulkan-first compatibility layer that lets software built for the Xbox Series X|S run on Linux with AMD GPUs, starting from openly licensed work. The first milestone is a research campaign: understand what existing open projects already do, under which licences, and what can be legally reused.

> VIE is an independent project. It is not affiliated with or endorsed by Microsoft, AMD, any game publisher, or the authors of the projects it studies. It contains no SDKs, keys, firmware, game files or leaked material and never will. See [LEGAL.md](LEGAL.md).
